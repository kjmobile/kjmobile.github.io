Privacy policy

Effective 10 September 2026 · Applies to the application predictive listening

What the application is

predictive listening is a private tool operated by one person to manage that person's own YouTube channels. It is not distributed, sold, or offered to anyone else. There are no user accounts other than the operator's own Google account.

What Google data it accesses

With the operator's authorization, the application uses the following Google APIs:

  • YouTube Data API v3 — to upload videos, set titles, descriptions, tags and thumbnails, schedule publication, and manage playlists on the operator's channels.
  • YouTube Analytics API (read-only) — to read view counts and related statistics for the operator's channels.

The application only reads and modifies content on channels owned by the authorizing account. It does not access other users' data.

How data is stored and shared

  • OAuth tokens are stored locally on the operator's own computer. There is no server and no hosted database.
  • Data obtained from Google APIs is used solely to operate the channels described above.
  • No data is sold, shared with third parties, or used for advertising.

Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

This website is static. It sets no cookies, runs no analytics, and collects no information about visitors.

Revoking access

Access can be revoked at any time from the Google Account page under Security → Third-party apps & services. Revoking access immediately invalidates the stored tokens.
