predictive listening

Publishing tools for the YouTube channels Predictive Listening and 英語が聞こえる瞬間

predictive listening is a private, single-operator application. It uses the YouTube Data API and YouTube Analytics API to upload, schedule, and organize short English-listening videos on two YouTube channels run by the operator, and to read those channels' own statistics.

The application is not offered to the public. The only Google account connected to it belongs to the operator, and it only ever acts on channels that account owns.
